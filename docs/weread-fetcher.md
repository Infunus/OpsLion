# 前端公众号采集

OpsLion 的周报页面内置公众号采集。目录通道使用随项目提供的 [weread-mp-fetcher](https://github.com/Pengyf04/weread-mp-fetcher)，固定提交 `3944db5e6df3dfb7c12d1ac2fddb902361cbc781`；OpsLion 提供浏览器启动、公众号管理、日期采集、正文解析和资料打包。无需另行部署或配置 RSS。

## 首次使用

本入口面向 Windows，需要排版台正常运行所需的 Node.js 22.13+、Python 3.10+，以及受支持的系统默认浏览器（Edge、Chrome、Brave、Vivaldi 或 Chromium）。

1. 双击 **启动排版台.bat**，进入 **周报 → 公众号采集**。也可双击 **启动公众号采集.bat** 直接打开周报页面。
2. 若显示 **初始化采集环境**，点击该按钮。程序自动在本机运行目录创建独立 Python 环境，安装正文解析所需的三个依赖；已有可用环境时直接复用。首次初始化需要联网，页面会显示进度和失败原因。
3. 打开 **公众号与登录 → 扫码登录**，二维码直接显示在排版台。用微信扫一扫，并在手机上确认；页面会自动更新登录状态。微信读书在这里提供公众号文章通道，导出仍保留微信公众平台的原文链接。
4. 检测到人机验证时，程序会暂停请求并**自动打开默认浏览器的验证页面**。在窗口完成验证，登录阶段回到排版台点击 **检查登录**，采集阶段点击 **继续上次任务**。未自动弹出或误关窗口时，点击 **重新打开验证页面**。二维码过期后可重新获取。
5. 粘贴目标公众号的一篇推文链接，点击 **添加公众号**；也可点击 **读取微信读书书架**，从已加入书架的公众号中选择。选中后才加入本机采集名单。
6. 关闭管理窗口，选择起止日期，点击 **采集正文并打包**。默认上一完整周的周一至周日，包含两端，按北京时间计算。
7. 完成后在 **已生成的资料** 下载 **资料 ZIP** 或 **纯文字**。

采集会话在后台自动启动。程序读取 Windows 的默认浏览器设置，支持 Edge、Chrome、Brave、Vivaldi 和 Chromium；不会把已配置的其他默认浏览器静默替换成 Chrome。默认浏览器不受支持时，页面会明确提示。切换浏览器使用不同的独立资料目录，需要在新浏览器扫码一次。公众号可在管理窗口中暂停、启用或移除；移除保留已下载文章。**清除本机授权** 会清除当前采集会话的登录信息，保留订阅与资料。

二维码仅通过本机接口提供，最多等待五分钟，停止、过期或完成登录后立即失效。界面不返回 Cookie、登录令牌或二维码原始授权地址。关闭管理窗口后，仍可重新打开查看正在进行的登录；点击 **停止扫码** 可取消。

## 导出与继续任务

- **采集正文并打包**：按日期读取启用公众号的目录，再取得普通图文正文、图片帖完整配文和原图，最后打包。
- **导出已有资料**：使用最新目录，不重新采集目录；缺少的正文会补取，已缓存正文会复用。全部正文已有缓存时可关闭采集浏览器后打包。
- **停止任务**：停止后续请求，当前请求结束后保存进度。已取得的目录、正文和图片保留。
- **继续上次任务**：继续上次失败、暂停或停止的日期任务，跳过已完成内容。目录翻页尚未覆盖开始日期时可继续读取更早页。
- 刷新页面或切换排版工作区后，仍可查看后台任务。关闭本地服务会中断任务，重启后可以继续。

验证、登录失效或请求失败时暂停整批，不会逐篇重复请求验证页面。每天默认两次目录采集，目录、正文与书架操作共用 40 次请求预算；每篇正文请求至少间隔 3 秒。预算用完时保存进度，次日继续。书架中已确认的公众号短时间内可直接加入本机名单，无需重复请求。这些是本机工具的默认限制，不是微信承诺的可用额度。

登录、阅读页面或正文请求明确出现人机验证时才自动弹窗；网络错误、权限不足、二维码过期或本机预算耗尽不会触发弹窗。同一次验证只自动打开一次，刷新排版台不会重复打开。窗口使用当前采集会话；从后台切换为可见窗口时，页面会重新加载，若要求重新扫码，请在该窗口完成。已下载内容保留，验证后的续传会复用缓存。

## 资料内容

- `all-text.md`：全部文章的文字正文汇总，可直接交给生成周报文案的 Skill。
- `all-articles.md`：带配图引用的全文汇总。
- `articles/`：逐篇 Markdown 和 HTML，含公众号、发布时间和原文链接。
- `assets/`、`asset-index.json`：配图及来源、所属文章。
- `index.json`、`manifest.json`：文章索引、正文数量、日期覆盖与缺失项。

正文或图片缺失、目录未覆盖开始日期时，页面显示缺失清单，下载按钮为 **下载现有资料 ZIP**，文件名带“含缺失项”，`archive_complete` 为 `false`。

微信读书可能漏收或延迟收录。资料完整只表示所选目录中的文章与配图已保存，`collection_coverage_confirmed` 始终为 `false`。视频、音频通过原文查看；图片中的文字未做 OCR。此通道独立保存资料，不写入可选的原版 RSS 数据库。

## 数据与发布

全新安装的授权状态、订阅名单和资料列表均为空。随项目提供的是 `integrations/weread-mp-fetcher/` 中的上游代码与许可证，以及 OpsLion 接入代码。

运行资料默认保存到 `%LOCALAPPDATA%/OpsLion/collector/`，包括独立浏览器资料、订阅配置、任务记录、正文缓存和导出包，不放入源码目录。升级已使用旧采集入口的安装时，沿用本机 `config/local.paths.json` 中已有的 `weread_fetcher_data_dir`，保留本机订阅和缓存；新安装不会从 RSS 数据库导入订阅或授权。

GitHub 版本不附带浏览器资料、Cookie、公众号名单、文章或个人路径。原版 RSS 是可选的高级功能，通过 **周报 → 原版 RSS（可选）** 进入；其安装说明见 [RSS 接入说明](rss-integration.md)。

## 本地接口

接口由排版台本地桥接服务提供，前端使用 `/local-api/collector/`，无需额外启动 Node 服务。

| 接口 | 用途 |
| --- | --- |
| GET `/collector/status` | 环境、登录检查结果、订阅、请求预算、当前任务与已有资料 |
| GET `/collector/login-qr?id=...` | 当前扫码任务的二维码 PNG；禁止缓存，过期或结束后拒绝访问 |
| POST `/collector/actions` | 启动异步操作，立即返回 `job_id` |
| POST `/collector/cancel` | 传入 `job_id` 停止对应任务 |
| GET `/collector/download?id=...&kind=zip` | 流式下载指定资料 ZIP |
| GET `/collector/download?id=...&kind=text` | 下载该资料的纯文字汇总 |
| GET `/collector/download?id=...&kind=index` | 下载文章索引 |

`actions` 的 `action` 支持 `initialize`、`login`、`open-browser`、`check`、`shelf`、`resolve`、`add`、`update`、`logout`、`collect`、`export`、`resume`。`login` 启动后台扫码并自动观察登录结果；工作进程返回 `code: verification` 时，服务端暂停任务并自动显示默认浏览器中的验证页面，任务结果的 `browser_opened` 表示打开是否成功。验证页面地址只保存在本机私有目录。`open-browser` 可手动重新打开待处理的验证页面或登录窗口。`resolve` 使用 `url` 添加公众号，`add` 使用书架的 `bookId`；`update` 使用 `bookId` 和 `operation`（`pause`、`resume`、`remove`）；采集与导出使用 `start_date`、`end_date`；继续任务使用 `job_id`。

状态协议为 `opslion-collector/v1`。任务状态为 `running`、`cancelling`、`complete`、`paused`、`failed`、`cancelled`。同时仅允许一个操作，旧任务编号不能取消新任务。下载只接受服务生成的资料编号和固定文件类型，不能传入任意本机路径；资料响应禁止浏览器公共缓存。本机接口不返回 Cookie、浏览器资料路径或 Python 路径。
