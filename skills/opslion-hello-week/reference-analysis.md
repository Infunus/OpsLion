# 模板沿革与设计说明

## 资料来源

- **新视觉基准**：用户上传《Hello Week丨26春 第十周》的 `xiumi-bridge/v4` 原生抓取包；本包的 `hello-week.template.json` 包含从该稿提取并清理的真实组件树
- **旧用法参考**：`hello-week-template-v1` 的 README、18 种模块说明、五种 Markdown 组合示例、固定素材清单和离线预览

## 哪些东西延续了

上周回顾 / 下周及后续、学术与活动分类、条数可变、投稿、过渡、重要提醒、联系方式、文案排版校对、固定图片和动态空栏目省略，仍然属于长期复用的内容约定。

## 哪些东西改变了

旧版主要通过 Markdown 语法驱动 HTML 模块，使用 `xiumi-bridge/v3`。新版的生成工具从**原生秀米 v5 组件树**复制、组合、修改文本片段，输出 `xiumi-bridge/v4`，在秀米内依然可以选中原生组件编辑。

旧版 18 个概念并不与新稿的 14 个种子一一对应。新模板只承诺当前真实拥有的 14 种。`news_panel` 内部又可组合出无数“类别 + 新闻标题 + 新闻正文”实例。

## 样式来源

保留顶部栏目动图、代码开场、投稿的浅蓝边框与装饰头像、黄色分区图标、渐变类别标签、蓝底白字资讯标题和浅蓝正文、`printf` 过渡与代码收尾、落款图。

本包的 `preview/` 只是为了方便浏览**栏目顺序与信息密度**而制作的离线示意页；不会替代秀米真实组件，也不作为输出源。所有正式成稿只能由 `hello-week.template.json` 的原生种子生成。

## 固定图像

`assets/` 内提供四个与新源稿一致的辅助预览原始素材：`banner.gif`、`avatar.gif`、`section.png`、`footer.jpg`。投稿二维码的源稿地址与旧版包不同，未直接套用旧版 QR 文件。百讲演出当前不自动填充海报，仅保留可编辑空白文本框。投稿二维码是否仍有效需要确认。

## 版本边界

- v1 旧内容 Markdown 不直接适配 v2.2 生成脚本
- 新版直接导入包已统一 `xiumi-bridge/v4`
- 导入端应支持 xiumi-bridge/v4 原生协议；本模板的每一种页面组合仍需按期检查实际导入、保存与渲染效果

## 2.2 调整：百讲演出固定保留

百讲演出源自《26春 第十周》原生 `shows_panel`。目前保留蓝色标题及浅蓝方框，移除旧海报及详情链接，改为一个空白可编辑原生文本框。它每期总是出现，位置在“下周及后续”之后、“重要提示”之前，内容由用户在秀米中自行完成。
