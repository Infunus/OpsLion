# 版本说明

## 发布配置更新：默认原文超链接

- 默认开启原文超链接，直接使用采集结果中的地址；缺失地址时保留文字并提示，不拼接地址
- 显式 `links_enabled:false` 仍可关闭；原标题链接不加下划线
- 此约定覆盖下方历史版本中“默认不插可点击链接”的说明

## v4.0.1 — 固定版式优先，取消长文自动缩进

- 明确 Hello Week 采用固定栏目骨架，原生组件的灵活性主要用于资讯分类、条目和字段，不套用通用排版 Skill 的自由编排规则
- 移除超过 70 字正文自动首行缩进的行为，常规资讯（无论长短）默认不缩进；`first_line_indent: "auto"` 兼容旧输入但按无缩进处理
- 西文打断不再自动开启，仅当条目显式选择 `western_break: true` 或 `"auto"` 时生效
- 保留单条正文按实际视觉需求显式应用秀米原生缩进的技术能力；百讲空白框及其他固定模块不受影响


## v4.0.0 — 合并版 Skill

- 将旧 OpsLion Hello Week Copy Skill v3.1.0 的资料读取、时间归档、跨公众号去重、更新/取消处理、证据追踪、事件文案与采编复核纳入当前原生模板
- 维持原生设计种子 v2.3、14 类秀米 v5 原生组件及六类组合示例
- 统一输出 `xiumi-bridge/v4` `.xiumi.json`，不再使用旧版 Markdown `:::news`/HTML 模块与旧 Markdown 验证器
- 以新约定覆盖旧冲突：回顾只收与信科本科生直接相关事项；预览只收本科生可参与或明确相关事项；默认不插可点击链接；段末不加句号；已结束活动去掉无价值报名统计
- 固定百讲演出原生方框，内部恰好一个空白文本框，禁止自动填充
- 引入轻量 JSON 审稿提示，原生生成器支持按需段落缩进与长西文打断
