# 合成技术样例（非真实秀米母版）

此目录仅演示 `xiumi-bridge/v4` 的字段、槽位替换以及**针对单一模块实例**进行样式修改。

- `native.template.xiumi.json`：虚构两个基础模块（文字模块与图片模块），结构精简以便说明和单元测试
- `layout.plan.json`：把一个短标签改成较长的通用栏目说明，仅为这一实例修改原有高度属性；另一个复用实例保持原值

样例中具体 `height`、`flex` 数值仅为测试样例，**不代表适用于真实秀米页面的修复方式**。样例中的模板模型也没有经过真实秀米编辑器验证，不能用它代替用户自己抓取的原生组件树。

## 如何理解这些示例

这里只证明“可以用同一模块产生多个实例”和“只对指定实例修改样式”的技术能力；示例中的模块顺序不代表实际文章顺序。面对真实文案时，应先建立原稿大纲，再从抓取包中判断哪些模块充当标题、正文、分割线、图片及图注，重新生成 `sequence`。参见 `references/composition.md` 与 `references/typography.md`。

## 秀米原生文字格式示例

`typography.plan.json` 演示在复用文本组件时，只修改一个实例的段落缩进与西文打断。生成器使用 `textFormatting`，会保留来源文本节点，针对实例创建 `<p style="text-indent: 2em; word-break: break-all;">` 及 `constraint.wordBreakMode = "breakAll"`。

注意示例里的中文叙述和长西文仅为两项技术能力的合成组合，**真实稿件只对需要的选项分别开启**。
