# 运营狮统一插件 0.9.0

同一个插件提供秀米原生排版抓取、导入，以及公众号采集台。

在 Edge / Chrome 的扩展管理页开启开发者模式，加载本目录。需要浏览器 116 或以上版本，无需 Node.js、Python 或本地服务。

- **抓取排版**：在秀米打开源稿件，下载 `.xiumi.json`，交给排版 Skill 处理。
- **导入排版**：在秀米另一份空白图文中导入 Skill 生成的 `xiumi-bridge/v4` 原生包。自动保存失败时先手工保存。
- **公众号采集**：打开采集台，微信扫码登录、添加公众号，按日期或全部历史采集正文与配图。

采集台保留停止、续传、自动打包下载和“修复原文链接并重新打包”。微信读书的 `WR…` 内部标识不会直接拼成公众号短链接；真实地址取自文章元数据并核对标题及公众号。采集时保持采集台标签页打开，遇到验证按提示操作。

升级时覆盖原加载目录后重新加载扩展，可沿用本机存储。旧 ZIP 不会自动修改，修复后请下载新资料包。完整使用说明及 Skill 入口见发布包根目录 README.md。

秀米原生核心沿用原 Bridge 0.6.8 实现，公众号模块来自 Collector 0.8.1，统一入口与版本为 0.9.0。文件兼容性依据 v4 原生协议，Skill 无需绑定插件版本号。

`collector/link-metadata.js` 和链接身份校验参考 weread-mp-fetcher 的 MIT 实现，其许可证在 `collector/weread-mp-fetcher-LICENSE`。JSZip、DOMPurify 的许可证保留在 `vendor/`。发布文件没有预填用户会话或采集资料。
